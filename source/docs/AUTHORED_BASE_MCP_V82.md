# Authored-base MCP integration — private v82

The editor bridge, native host and both MCP servers now expose `capture_authored_base` and `place_authored_base`. Capture reads the active entity projection and current validation settings at an explicit revision. Placement uses the shared authored-base operation; preview returns the candidate without mutation, while apply commits through the normal one-step Undo path and verifies revision advancement.

Both tools require an explicit session and current revision. Capture takes `activeLayoutId` and `sourceFrame: {origin:[x,y,z],yaw}`. Placement takes the returned `packageJson`, explicit `previewOnly`, and `authoredRequest: {activeLayoutId,layoutId,frame,terrainMode}`. The layout ID must be new. Coordinates are world XYZ; yaw is radians. Terrain mode is `preserve` or `conform`. See [placement semantics and limits](AUTHORED_BASE_PLACEMENT.md), including locked starships, conservative preserved-model bounds, sampled conformance and rectangle quarter-turn restrictions.
